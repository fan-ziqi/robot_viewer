# Base Pose Controls UI 使用指南

## 第一步：启动前后端

在项目根目录运行：

```bash
pnpm run dev:all
```

这将同时启动：
- 前端服务器：`http://localhost:3000`
- 后端服务器：`http://localhost:3001`

> **注意**：后端服务器必须运行才能保存和读取帧文件。

## 第二步：加载机器人模型

1. 打开浏览器访问 `http://localhost:3000`
2. 将 URDF 或 MJCF 文件拖拽到页面中
3. 等待模型加载完成

## 第三步：打开基座姿态面板

点击工具栏中的 **"Base Pose"** 按钮，右侧会显示基座姿态控制面板。

## 第四步：调整机器人姿态

### 调整位置
- 使用 **Position (World)** 区域的 X、Y、Z 滑块调整机器人位置
- 或直接在右侧数值框输入精确值

### 调整姿态
- 使用 **Orientation (RPY)** 区域的 Roll、Pitch、Yaw 滑块调整机器人旋转
- 或直接在右侧数值框输入精确值

### 设置帧时间
- 在 **"Frame Time (s)"** 输入框中设置当前帧的时间戳（例如：0.0、1.5、2.0）

## 第五步：保存帧

1. 调整机器人到目标姿态
2. 设置帧时间
3. 点击 **"Save Frame"** 按钮

**会发生什么：**
- ✅ 当前机器人的所有关节角度、基座位置和姿态被保存
- ✅ 数据保存到 `frames/frame_{机器人名称}.json` 文件
- ✅ 帧数据同时复制到剪贴板
- ✅ 如果该时间点已有帧，会更新；如果没有，会添加新帧
- ✅ 自动重新加载帧列表

**示例：**
- 机器人名称：`go1_description`
- 保存位置：`frames/frame_go1_description.json`

## 第六步：读取帧

1. 点击 **"Load Frames"** 按钮

**会发生什么：**
- ✅ 从 `frames/frame_{机器人名称}.json` 读取所有已保存的帧
- ✅ 显示加载的帧数量
- ✅ 帧浏览滑块变为可用状态
- ✅ 自动加载最接近当前帧时间的帧

## 第七步：浏览帧

读取帧后，可以使用以下方式浏览：

### 方式 1：使用滑块
- 拖动 **"Browse Frames"** 滑块
- 实时预览不同帧的机器人姿态
- 释放鼠标后应用完整更新

### 方式 2：使用导航按钮
- **◀** 按钮：跳转到上一帧
- **▶** 按钮：跳转到下一帧

### 方式 3：输入帧时间
- 在 **"Frame Time (s)"** 输入框中输入目标时间
- 系统会自动找到最接近的帧并加载

## 第八步：线性插值转 LaFAN 格式

1. 确保已保存多个帧（至少 2 个）
2. 在插值区域的 **"Frequency"** 输入框设置频率（默认 60 Hz）
3. 点击 **"Interpolate to LaFAN Format"** 按钮

**会发生什么：**
- ✅ 读取所有保存的帧
- ✅ 按时间排序
- ✅ 根据设置的频率进行线性插值（例如 60 Hz = 每秒 60 帧）
- ✅ 生成 CSV 文件并保存到 `frames/lafan/{机器人名称}.csv`
- ✅ 显示成功通知，包含插值帧数和保存路径

**示例：**
- 输入：3 个帧，时间范围 0.0s - 2.0s，频率 60 Hz
- 输出：约 120 帧的 CSV 文件（2 秒 × 60 帧/秒）
- 保存位置：`frames/lafan/go1_description.csv`

## 常用操作

### 重置基座姿态
点击 **"Reset Base Pose"** 按钮，机器人恢复到加载时的初始位置和姿态。

### 查看帧信息
- 滑块右侧显示当前帧的时间戳（格式：`X.XXXs`）
- 例如：`1.500s` 表示第 1.5 秒的帧

## 文件位置

所有文件保存在项目根目录的 `frames/` 文件夹下：

```
frames/
├── frame_{机器人名称}.json    # 保存的帧数据
└── lafan/
    └── {机器人名称}.csv        # 插值后的 LaFAN 格式文件
```

## 提示

- 💡 保存帧前记得设置帧时间，否则会使用默认值 0.0
- 💡 可以多次保存不同时间点的帧，创建动画序列
- 💡 插值频率越高，生成的帧越多，文件也越大
- 💡 所有操作都会显示通知消息（成功=绿色，错误=红色）
